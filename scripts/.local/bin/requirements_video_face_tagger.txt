# Optional dependencies for video_face_tagger.py
#
# These enable the face pre-filter (--face-filter), which discards extracted
# frames containing no detectable face before digiKam ever sees them. On a
# sample of this archive it cut the frame count by 55% with no loss of
# recognisable faces.
#
# The tool runs fine without these; the filter simply stays off.
#
# Recommended install -- a venv beside the script, which is where
# video_face_tagger.py looks first:
#
#   cd "$(dirname "$(command -v video_face_tagger.py)")"
#   python3 -m venv .venv
#   .venv/bin/pip install -r requirements_video_face_tagger.txt
#   video_face_tagger.py fetch-model
#
# Note that fetch-model is a separate step: OpenCV 5 ships no bundled face
# detector, so the 233 KB YuNet model is downloaded (checksum-verified) into
# ~/.config/video_face_tagger/ on first use.
#
# The script re-executes itself under a virtualenv interpreter when it finds
# one, so there is no shebang change and nothing to activate. An already
# active virtualenv always wins; otherwise .venv or venv beside the script is
# used, then ~/.local/share/video_face_tagger/venv. Set
# VIDEO_FACE_TAGGER_PYTHON to override. Use --verbose to see which
# interpreter is running.

opencv-python-headless>=4.8
numpy>=1.24

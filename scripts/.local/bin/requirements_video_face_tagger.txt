# Optional dependencies for video_face_tagger.py
#
# These enable the face pre-filter (--face-filter), which discards extracted
# frames containing no detectable face before digiKam ever sees them. On a
# sample of this archive it cut the frame count by 55% with no loss of
# recognisable faces.
#
# The tool runs fine without these; the filter simply stays off.
#
# Recommended install:
#   python3 -m venv ~/.local/share/video_face_tagger/venv
#   ~/.local/share/video_face_tagger/venv/bin/pip install \
#       -r requirements-video_face_tagger.txt
#   video_face_tagger.py fetch-model
#
# video_face_tagger.py picks that venv up automatically; no shebang change
# and no need to activate anything.
